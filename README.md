# FuelFinder

주유소 표시가격뿐 아니라 차량 연비와 이동비를 반영해 실질 주유비를 비교하는 Node.js 웹 앱입니다.

## 현재 기능

- 오피넷 주변 주유소 검색
- 주소·장소명 검색 후 해당 위치에서 즉시 주유소 검색
- 보통휘발유 / 고급휘발유 / 자동차용경유
- 차량 주유량 및 연비 반영
- 왕복 이동비 반영
- 일반 할인 계산
- 강릉페이 공식 주유소 목록 기반 매칭
- 상호명과 주소를 이용한 주유소 식별
- 오피넷 상세정보 선택 조회
- `UNI_ID` 기준 7일 로컬 캐시
- 실질가격순 / 주유가격순 / 거리순 정렬
- 강릉페이 가맹점만 보기
- 최근 검색 위치 저장 및 재검색
- 동일 위치·조건의 주변 검색 60초 서버 캐시로 오피넷 중복 호출 최소화
- 주유가격 최저와 실질비용 최저의 차이 안내
- 주유소별 상세 계산 접기/펼치기

## 로컬 실행

```powershell
npm.cmd install
npm.cmd start
```

브라우저: `http://localhost:3000`

## 환경변수

`.env.example`을 참고해 `.env`를 만듭니다.

```text
OPINET_CERTKEY=...
```

- `OPINET_CERTKEY`: 오피넷 API 조회에 필수입니다. 이게 없으면 서버가 주유소 검색 자체를 못 합니다.

주소 검색은 서버에서 OpenStreetMap Nominatim을 중계하며 별도의 주소 검색 API 키를 사용하지 않습니다. 공개 지오코더의 요청 제한을 고려해 서버 메모리 캐시와 요청 간격 제한을 적용했습니다.
- `LOCALPAY_SERVICE_KEY`: 운영 서버(`src/server.js`)는 사용하지 않습니다. `src/legacy/`의 예전 스크립트(한국조폐공사 실시간 API 연동 시도)를 직접 돌려볼 때만 필요합니다. 로컬에서 그 스크립트를 실행할 계획이 없다면 설정하지 않아도 됩니다.

`.env`는 GitHub에 올리지 않습니다.

## Render

이 저장소는 Render Web Service 기준으로 구성되어 있습니다. `render.yaml`을 사용할 수 있습니다.

- Build Command: `npm ci`
- Start Command: `npm start`
- Health Check Path: `/health`

Render 환경변수에는 `OPINET_CERTKEY`만 등록하면 됩니다. Render Web Service는 `PORT` 환경변수를 제공하며 서버는 이를 사용합니다.

## 캐시

오피넷 상세정보는 `UNI_ID` 기준으로 최대 7일간 로컬 캐시합니다. Render의 일반 로컬 파일은 영구 저장소가 아니므로 캐시는 재배포나 인스턴스 교체 후 사라질 수 있습니다.

## 계산 로직

실질 주유비·할인 계산은 `public/shared/calc.js` 한 곳에만 있습니다. 서버(`src/calculator.js`, `src/discount.js`, `src/index.js`)와 브라우저(`public/index.html`)가 이 파일을 그대로 가져다 씁니다. 계산 공식을 고칠 일이 생기면 이 파일 하나만 고치면 됩니다 — 서버/프론트에 따로따로 반영할 필요가 없습니다.

## 주의

강릉페이 10% 캐시백 정책의 적용 여부와 기간은 별도로 관리해야 합니다. 현재 저장소의 `src/gangneungPayStations.js`는 제공받은 공식 사용 주유소 목록을 기준으로 하는 **고정 리스트**이며, 실시간으로 갱신되지 않습니다. 가맹점이 새로 생기거나 빠지면 이 파일을 직접 수정해야 반영됩니다. 강릉페이 공식 공지가 바뀔 때마다(또는 최소 분기 1회) 목록을 다시 확인하는 걸 권장합니다.

## src/legacy

운영 서버가 쓰지 않는 이전 구현(한국조폐공사 실시간 API 연동 시도, 초기 매칭 엔진 등)은 `src/legacy/`에 분리되어 있습니다. 자세한 내용은 `src/legacy/README.md` 참고.

### 가격 최신성 표시

- 오피넷 `detailById.do`의 `TRADE_DT`/`TRADE_TM`을 이용해 확인 가능한 주유소의 가격 기준일을 표시합니다.
- 2일 이상 지난 가격은 기본적으로 결과에서 제외하며, `2일 이상 지난 가격 제외` 버튼으로 해제할 수 있습니다.
- 가격 기준일을 확인하지 못한 주유소는 별도로 표시하며 자동으로 제외하지 않습니다.
- 상세 주유소 정보 캐시는 24시간까지만 사용하여 며칠 전 가격정보가 계속 고정되는 것을 방지합니다.
- 가격 기준일 확인은 오피넷 일반 API 호출량을 고려해 검색 결과 중 가격순 상위 후보와 강릉페이 확인 대상부터 수행합니다.

- 지도/길찾기: 주유소 카드의 지도 버튼은 오피넷 위도·경도를 목적지로 사용합니다. 네이버지도는 현재 위치→주유소 자동차 길찾기 앱 URL을 사용하고, 카카오맵은 좌표 목적지 길찾기 바로가기를 사용합니다.

## 카카오내비 / 지도 연결

주유소의 오피넷 WGS84 좌표를 사용해 지도앱에서 다시 이름을 검색하지 않고 목적지를 지정합니다.

- `네이버 길찾기`: 현재 위치를 출발지로 하는 자동차 길찾기
- `카카오내비`: Kakao JavaScript SDK의 `Kakao.Navi.start()`로 현재 위치에서 주유소까지 길안내
- `네이버 도착 위치`: 네이버 지도 앱을 주유소 좌표에 확대해 표시(줌 18)
- `카카오 도착 위치`: 카카오맵에서 주유소 좌표를 중심으로 표시

카카오내비 연동에는 카카오디벨로퍼스에서 발급한 JavaScript 키와 FuelFinder 도메인의 JavaScript SDK 도메인 등록이 필요합니다. 배포에서는 Render 환경변수 `KAKAO_JAVASCRIPT_KEY`로 키를 설정합니다. 카카오 로그인 리다이렉트 URI는 사용하지 않습니다.

카카오 JavaScript SDK는 2.8.3을 사용합니다.
